# Prompt Library

A personal subsite (subdomain of jechav.dev) for storing, browsing, and managing reusable AI prompts. The listing is publicly viewable; creating and editing requires authentication.

## Language

**Prompt**:
A reusable piece of text authored by the owner, intended to be sent to an AI model. Has a title, content, and one or more tags.
_Avoid_: snippet, template, message

**Prompt Library**:
The subsite application that stores and surfaces Prompts.
_Avoid_: prompt manager, prompt store, prompt hub

**Tag**:
A free-form label applied to a Prompt for categorisation. Entered freely; autocompleted from existing tags in the library.
_Avoid_: category, label, keyword

**Listing**:
The main page of the Prompt Library — a grid of Prompt Cards showing recent prompts, with a search bar and tag filter in the header.
_Avoid_: homepage, dashboard, feed

**Prompt Card**:
A compact preview of a Prompt shown on the Listing — displays the title, a short content preview, and its tags.
_Avoid_: tile, item, row

**Prompt Modal**:
The modal dialog used for both creating and editing a Prompt. Pre-filled with existing data when editing.
_Avoid_: form, dialog, drawer
